### 컨테이너 기초
#### Docker
애플리케이션을 컨테이너 내에서 빌드, 배포, 실행할 수 있게 하는 오픈소스 도구이다.
도커를 이용해 모든 환경에서 일관되게 실행하고 배포할 수 있다.

#### Dockerfile
도커 이미지를 생성하기 위한 스크립트 파일로 필요한 명령어나 설정 등을 담고 있다.

#### Image
Dockerfile을 통해 생성된 이미지는 애플리케이션 실행에 필요한 것들을 포함한 읽기전용 스냅샷으로 어느 환경에서든 동일하게 실행될 수 있도록 해준다.

#### Container
애플리케이션 실행에 필요한 모든 것을 포함하여 경량화되고 독립적으로 실행되는 단위를 뜻하며 Docker는 컨테이너를 관리할 때 사용하는 도구라고 볼 수 있다.

#### Registry
컨테이너 이미지 전용 저장소로 컨테이너 이미지를 중앙에서 저장하고 관리하며 언제든 pull 또는 push할 수 있도록 한다.

### 컨테이너 관리, 네트워크, 프록시
#### Volume
Docker container는 기본적으로 무상태이기 때문에 컨테이너 외부에 별도의 저장 영역을 제공하여 데이터를 영구적으로 보존하고 여러개의 컨테이너가 공유하고 재사용할 수 있게 해주는 저장소이다. 따라서 상태를 유지해주는 수단이라고 볼 수 있다.

#### Bridge Network
여러개의 컨테이너 간의 네트웍을 공유하고 연결해주는 네트워크 방식이다.

#### Reverse Proxy
클라이언트와 서버 사이에서 중개 역할을 하는 서버이다.

#### Docker Compose
Docer의 오픈소스 도구로 여러 컨테이너로 구성된 애플리케이션을 YAML 파일로 정의하고, 단일 명령어로 동시에 실행 및 관리할 수 있게 해주는 도구이다.

### CI/CD 도구
#### Continuous Integration(CI)
자동으로 코드를 통합 및 테스트하게 해주는 개발 프로세스다.

#### Continuous Deployment(CD)
CI 통과 후 운영 환경으로 자동으로 배포되는 배포 프로세스다.

#### Github Actions
위에서 정의한 CI/CD를 Github 내에서 수행하게 해주는 도구로, 빌드, 테스트, 배포를 자동화 해준다.
