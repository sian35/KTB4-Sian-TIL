## 주제: LLM Optimization
- LLM Optimization이란 큰 모델을 작고 빠르고 저렴하게 다룰 수 있도록 만들어서 모델을 실제로 사용할 수 있는 상태로 바꾸는 작업을 의미한다.
### 데이터 타입
#### FP32 (Floating Point 32)
- IEEE 754 단정밀도(Single Precision) 부동소수점 형식
- 하나의 실수를 32비트로 표현
- 부호 1비트, 지수 8비트, 가수 23비트
#### FP16 (Floating Point 16)
- IEEE 754 반정밀도(Half Precision) 부동소수점 형식
- 하나의 실수를 16비트로 표현
- 부호 1비트, 지수 5비트, 가수 10비트
#### BF16 (Brain Float 16)
- FP16과 같은 16비트지만, 비트를 나누는 방식이 다른 부동소수점 형식
- 부호 1비트, 지수 8비트, 가수 7비트
- 핵심은 FP32처럼 넓은 숫자 범위(지수부 비트 수가 같음)를 유지하면서 저장 공간은 16비트로 줄였다는 점이다.
- 단점은 숫자를 세밀하게 저장하지 못한다.

#### Mixed Precision Training
- 과정마다 데이터 타입을 다르게 적용하는 기법이다.
- 무거운 연산은 저비트로 빠르게 처리하고, 가중치 누적과 업데이트는 FP32로 처리하여 속도와 메모리 효율성을 챙김과 동시에 수치 안정성을 확보하는 학습 기법이다.
#### INT8
- 하나의 값을 8비트로 저장
- 부호 있는 형식에서 -128부터 127까지 총 256개의 정수를 표현하는 데이터 타입이다.
#### INT4
- 하나의 값을 4비트로 저장
- 부호 있는 형식에서 -8부터 7까지 총 16개의 정수를 표현하는 데이터 타입이다.

### Quantization (양자화) 기법
- 양자화는 높은 비트 수로 저장된 모델 파라미터를 낮은 비트 수로 변환하는 경량화 기법이다.
- 이는 단순한 데이터 타입 변환이 아니라 메모리를 줄이면서도 정확도 손실을 적게 하면서 균형점을 맞추는 최적화 과정이다.

### 무엇을 양자화 할 것인가
#### Affine Quantization 
- Scale factor과 Zero-point를 이용하여, 부동소수점 값을 정수 범위로 affine 변환하는 양자화 기법이다.
- Affine : 선형 변환에 평행 이동이 더해진 변환
- Scale factor : 부동소수점 값의 간격을 정수 한 칸의 간격에 맞춰서 조정하는 비율
- Zero-point : 부동소수점 0의 위치를 정수 범위의 어디로 옮길지 정하는 기준점
- 역양자화 : 정수값에서 부동소수점 범위로 복원하는 것
    - 양자화 과정에서 반올림이 발생하기 때문에 양자화 오차가 생긴다.

#### Weight Quantization
- 학습된 가중치를 저비트로 변환하는 양자화 기법
- per-tensor : 가중치 텐서 전체에 하나의 scale을 적용
- per-channel : 출력 채널별로 별도의 scale을 적용
- per-group : 가중치 텐서를 더 작은 그룹 단위로 나눠서 그룹별로 별도의 scale을 적용

#### Activation Quantization
- 입력 데이터에 따라 달라지는 중간 출력 값인 활성화 값을 저비트로 변환하는 양자화 기법이다.
- 가중치는 학습이 끝나면 값이 고정되지만, 활성화 값은 입력 데이터에 따라 매번 달라진다.
- 방식
    - 대표 데이터를 미리 넣어 측정된 활성화 분포를 이용해 양자화
    - 추론 시점에 입력별로 활성화 범위를 측정하여 양자화

#### KV Cache Quantization
- 이전 토큰의 K,V vector를 저비트로 저장하여 KV cache가 차지하는 gpu 메모리를 줄이는 기법이다.
- 긴 문맥 추론에서 더 긴 시퀀스를 처리하고 많은 동시 요청을 수용할 수 있게 된다.
##### KV Cache
- 속도를 높이는 대신 GPU 메모리를 사용하기 때문에 양자화 기법을 사용하여 저비트 형식으로 저장하면 메모리 사용량을 줄일 수 있다.

#### Weight-only Quantization
- 학습된 가중치만 저비트로 저장하고 활성화 값은 원래 정밀도로 유지하는 양자화 기법이다.
- 가중치는 저비트로 GPU 메모리에 올라가지만, 행렬 곱셈에 사용할 때는 커널 내부에서 필요한 부분만 고정밀도에 가까운 값으로 복원해 사용한다. = on-the-fly 역양자화
- Decode 단계에서 속도 측면에서의 효과가 크다.
    - 대화형 챗봇 또는 단건 API 호출처럼 작은 배치로 토큰을 생성하는 환경에서 유리하다.

#### W8A8 / W4A16
- 양자화할 때 사용된 비트 수에 따라 표현
- W4A16 : Weight-only 양자화


### 언제를 기준으로 양자화 할 것인가
#### 1. PTQ (Post Training Quantization)
- 모델 학습이 끝난 뒤에 적용하는 양자화 기법이다.
- e.g.) GPTQ, AWQ, SmoothQuant, bitsandbytes 기반 4bit 로드
- 재학습 없이 모델 메모리와 추론 비용을 줄여, 이미 학습된 모델을 빠르게 배포할 수 있다.
- 동작 과정
    1. 학습된 원본 모델 로드
    2. 대표 데이터 준비 : Calibration
    3. 대표 데이터를 입력으로 가중치나 활성화 값의 범위와 분포 측정
    4. 양자화 파라미터 결정
    5. 저비트 변환 및 저장

##### Static Quantization, Dynamic Quantization
- 기준: **활성화 값의 양자화 기준**을 정하는 시점
- Static Quantization
    - 대표 데이터(Calibration data)를 이용해 활성화 값의 양자화 파라미터를 계산해 두고, 추론 시에는 그 값을 고정해 사용하는 양자화 기법이다.
    - 핵심은 활성화 값의 양자화 기준을 추론 전에 미리 정해둔다.
    - 추론 시 추가 계산을 줄이고, 지연 시간이 일정해진다. 또한 정수 연산 가속 효과를 얻을 수 있다.
    - 입력 크기와 분포가 비교적 일정한 경우에 사용 : 이미지 분류, 객체 탐지, 온디바이스 추론 환경
- Dynamic Quantization
    - 추론 시점에 입력 데이터의 분포를 보고 활성화 값의 양자화 파라미터를 그때 그때 계산해 적용하는 양자화 기법이다.
    - 활성화 기준을 미리 고정하지 않는다.
    - 적용이 간단하고 유연하게 대응할 수 있지만 추론 시에 분포 측정과 추가 계산이 필요하기 때문에 추론 경로에 비용이 좀 더 들게 된다.
    - 텍스트 모델처럼 입력 문장의 길이, 도메인이 크게 달라지는 경우에 사용

##### Calibration
- 대표 입력 데이터를 모델에 통과 시켜 활성화 값의 분포와 범위를 측정하는 절차이다.
- 저비트 변환 후에도 모델 정확도를 최대한 유지하기 위해서 사용한다.
- Calibration Data 조건
    - 소량
    - 대표성
    - 레이블 불필요
    - 실제 사용 도메인과 일치
- 과정
    - 대표 입력 준비
    - 대표 입력을 원본 모델에 통과시켜 순전파만 실행한다.
    - 활성화 통계를 수집한다
    - 양자화 파라미터를 산출한다.
    - 양자화를 적용한다.

#### 2. QAT (Quantization-Aware Training)
- 학습 과정 안에 양자화 효과를 미리 넣어서 모델이 양자화로 생기는 오차를 학습 중에 경험하도록 만드는 방식이다.
- 핵심 : Fake Quantization 노드를 학습 그래프에 삽입한다.
- PTQ와 달리 변환만 적용하는 방식이 아니라 추가 학습을 포함한다.
- 비트 수가 낮을 수록 양자화 오차가 커지기 때문에 QAT의 필요성이 커진다. 

##### STE (Straight-Through Estimator)
- 순전파에서는 `round`를 그대로 적용해 양자화 오차를 만들지만, 역전파에서는 `round`가 없었던 것처럼 기울기를 근사해서 통과시키는 방법이다.

#### Outlier Problem
- 극단 값이 양자화의 표현 해상도를 잠식해 저비트의 정확도가 떨어지는 현상이다. 
- 핵심 : 이상치 하나 때문에 전체 정수 칸의 간격이 커져서 대부분의 일반 값이 세밀하게 표현되지 못한다.
- LLM에서 outlier는 특정 채널, 토큰, 레이어 위치에 집중되어 나타나는 경우가 많다.
- 해결 방법: 이상치의 영향을 전체로 퍼뜨리지 않도록 scale 단위를 나누거나 이상치를 별도로 처리한다.
    - per-channel Quantization
    - per-group Quantization
    - Outlier 분리
    - Activation Smoothing
