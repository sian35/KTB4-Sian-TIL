### 고급 Quantization 기법
#### GPTQ (Generative Pre-trained Quantization) - PTQ
- Calibration 데이터를 사용해 가중치를 저비트로 변환할 때 오차를 계산하여 보정하는 PTQ 기법이다. 
- 핵심은 가중치를 양자화하면서 생긴 오차를 버리지 않고, 아직 양자화하지 않은 다른 가중치에 분배한다.
- cf. RTN(Round-to-Nearest) : 단순 반올림 방식
- 동작 과정
1. 캘리브레이션 데이터 입력
2. 레이어 입력 통계 수집
3. 민감도 정보(어떤 가중치의 오차가 출력에 큰 영향을 주나)를 계산
4. 오차 보상 : 양자화하면서 생긴 오차를 아직 양자화하지 않은 가중치 쪽에 반영한다.
5. 다음 가중치나 block에 대해 반복
6. 완료

##### Hessian
- 민감도 정보 : 가중치가 바뀌었을 때 출력이 얼마나 민감하게 흔들리는지 알려주는 정보
- 이를 통해 양자화 오차를 어디에 얼마나 분배할지 결정된다.

- Damped inverse Hessian : 실제 계산에 사용할 수 있도록 안정화한 형태

#### AWQ (Activation-aware Weight Quantization) - PTQ
- 활성화 값의 통계를 보고 출력에 중요한 가중치 채널을 찾아 해당 채널은 덜 손상되도록 스케일을 조정하는 PTQ 기법이다.
- Calibration 데이터를 사용해, 각 채널의 활성화 값을 측정한다. 
##### Salient Weight
- 양자화했을 때 출력에 큰 영향을 주는 중요한 가중치
- AWQ는 salient weight를 가중키 값의 크기만 보고 판단하는 것이 아니라 그 가중치가 연결된 채널의 활성화 값의 크기를 함께 본다. 

##### AWQ의 알고리즘: Per-channel Scaling
- 채널별 스케일링을 통해 중요한 채널의 가중치가 양자화 과정에서 더 잘 보존되도록 만든다.

#### Quantization Evaluation
- 양자화 모델을 배포해도 되는지 판단하는 과정이다.

### PEFT(Parameter-Efficient Fine-Tuning) 기법
- 사전학습된 원본 가중치 대부분을 고정하고, 소수의 파라미터나 프롬프트만 조정해 특정 작업에 적응시키는 파인튜닝 방법의 총칭이다.
- cf. Full Fine-Tuning : 전체를 학습
- PEFT 기법들
    - 어댑터, 가중치 수정
    - 양자화 결합
    - 병합, 결합
    - 프롬프트 기반

#### LoRA(Low-Rank Adaptation) - 어댑터, 가중치 수정
[LoRA 상세 설명](https://outcomeschool.com/blog/lora-low-rank-adaptation-of-llms)
- 원본 모델 전체를 다시 학습하지 않는다.
- 핵심은 원본 모델은 그대로 두고, 즉정 작업에 필요한 변화만 작은 어댑터로 학습한다. 
- 따라서 학습 파라미터가 줄어든다.
- rank : 작은 통로의 크기를 정하는 값
- 어댑터

#### QLoRA - 양자화 결합
- 4-bit NF4로 양자화된 기반 모델은 고정하고, 16-bit LoRA 어댑터만 학습해 메모리 사용량을 줄이는 PEFT 기법이다.

> LoRA와 QLoRA 공통점  
> 원본 모델 전체를 학습하지 않고, 작은 LoRA 어댑터만 학습한다.  
> LoRA와 QLoRA 차이점  
> QLoRA는 LoRA와 달리 기반 모델을 4bit로 두고 학습한다. 즉, 기반 모델을 메모리에 어떤 정밀도로 올리느냐에 차이가 있다.

##### Adapter Merge - 병합, 결합
- 학습된 어댑터를 원본 모델에 "붙여서 사용하는 상태"에서 어댑터 변화량을 원본 가중치에 미리 더해 "하나의 모델로" 바꾸는 과정이다.

##### Model Merge
- 이미 학습이 끝난 여러 모델을 다시 학습시키지 않고, 각 모델의 가중치를 규칙에 따라 섞어서 새로운 모델을 만드는 방법이다.
