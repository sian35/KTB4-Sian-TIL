## 주제: Linux
### Linux 기본 및 셸 환경
#### Linux 
유닉스 기반의 오픈소스 운영체제 커널이다.

#### Linux Shell
리눅스의 핵심인 커널과 사용자를 연결해주는 인터페이스이다. Linux shell에 명령을 입력해서 시스템을 직접 제어할 수 있다.  
Shell의 종류 : bash(aws서버를 통한 ubuntu), zsh(맥 os)

#### Crontab
리눅스에서 정해진 시간에 자동으로 명령이나 스크립트가 실행되도록 예약하는 명령어이다.  
백그라운드 동작 : cron 데몬
##### 데몬이란?
백그라운드에서 계속 동작하며 기능을 수행하는 시스템 프로세스를 의미한다.

#### File Permission
소유자, 소유자가 속한 그룹, 그 외 아무나 로 권한 설정이 나뉠 수 있다.

#### 환경 변수
다양한 프로그램이 동일한 설정을 공유하여 동작 방식을 일관되게 유지하게 하는 동적인 키-값 설정 정보이다.

#### SSH
Secured Shell  
암호화된 세션을 생성해 안전하게 원격으로 접속하기 위해 사용되는 네트워크 프로토콜이다.

#### Vi, Nano (편집기)
리눅스에서 사용되는 파일 편집기

### 텍스트 스트림 처리 도구
#### Pipe
이전 명렁어의 출력 결과를 다음 명령어의 입력으로 전달하는 기능이다. 

유닉스 명령어들
- cat, more, less : 파일 내용을 보는 명령어
- grep : 검색어를 서치  
e.g., ps -ef | grep python
- ps -ef : os상에서 실행되고 있는 프로세스 목록들
- head/tail : 가장 오래된 또는 가장 최신의 기록을 보기 위해 사용  
e.g., 최신 로그 볼 때, history(지금까지 사용한 모든 명령어)에서 최신 명령어 볼 때
- diff / CMP(compare): 두 파일을 비교하여 차이점을 보여줌
    - diff : 줄 단위로 비교하여 다른 부분이 어디인지 보여줌
    - CMP : 바이트 단위로 비교하여 처음 발생하는 불일치 지점이 어디인지 알려줌
- Sed : 데이터를 한 줄씩 읽어가며 패턴에 따라 내용을 자동으로 수정하는 편집 명령어이다.
- Awk : 데이터를 한 줄씩 읽고, 각 필드를 공백이나 지정된 구분자로 분리하여 처리하는 텍스트 분석 도구이다.

### 파일 및 시스템 관리
- Tar : 파일과 디렉터리를 하나의 아카이브 파일로 묶어 저장하는 도구
- Top / PS
    - Top : 실시간으로 실행 통계(프로세스 상태와 자원 사용량)를 보여줌
    - PS(Process Status) : 스냅샷 형태로 현재 시점에서 실행중인 프로세스 목록과 상태 정보를 보여줌
- Hard link / Soft link
    - Hard link : 원본 파일 삭제해도 링크해둔 것은 남는다
    - Soft link : 원본 파일 삭제하면 링크가 깨진다. (dead link)
- DU / DF
    - DU(Disk Usage) : 파일이나 디렉터리가 디스크에서 차지하는 사용량을 출력 
    - DF(Disk Free) : 파일 시스템 전체의 디스크 사용량과 남은 용량 확인

### 네트워크 및 패키지 관리
- apt : pip, uv같은 패키지 관리의 대명사
- curl : url을 통해 서버와 데이터를 주고받기 위한 명령어 기반 전송 도구
- wget : web에서 파일을 다운받게 해주는 명령어 도구
- Nslookup : 도메인과 IP 주소의 실제 DNS 응답을 확인하기 위한 도구
- Dig : 도메인 이름에 대한 DNS 정보를 조회하고 분석하는데 사용되는 질의 명령어이다.
- NTP : 인터넷 표준 시간 서버와 동기화하여 시스템 시간을 정확히 맞추는 프로토콜
- Ping : 네트워크 대상과의 연결 여부와 응답 속도를 확인할 수 있는 명령어 도구
- SS(Socket Statistics) : 소켓 상태(네트워크 연결 정보)를 빠르고 상세하게 조회하는 명령어
    - netstat은 더 이상 사용하지 않는다.
